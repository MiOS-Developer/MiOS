## Verdict

None of the fourteen audited stages came back clean, and the worst of it is already shipping. The single most dangerous finding is in **76-uki-render**: `tools/generate-uki-cmdline.py` wraps each `tomllib.load` in `except Exception: print(...)` and then *continues*, so a one-character syntax error in any `kargs.d` drop-in silently deletes that file's kernel arguments — corrupting `01-mios-hardening.toml` produced a cmdline with `spectre_v2`, `spectre_bhi`, `spec_store_bypass_disable`, `l1tf`, `gather_data_sampling`, `tsx`, `pti`, `vsyscall`, `randomize_kstack_offset` and `kvm.nx_huge_pages` all gone (1408 → 1214 bytes), `Generated ...`, `EXIT=0` — and the drift gate then prints `[OK] usr/lib/kernel/cmdline is in sync with kargs.d/*.toml` because `build.sh:392` reprojects the file before `98-drift-checks.sh:2690` re-runs the same generator with `2>/dev/null`. That is the live python path, not a Rust conversion hazard. Close behind, and also live: **33-generate-quadlets** bakes `Environment=POSTGRES_PASSWORD=<value>` into `0644` files under `/usr` and lets a build-env `MIOS_ADGUARD_UID=0` write `User=0` into a unit that is not on the privileged roster, under a header certifying it as SSOT-derived; **49-cosign-policy** ships `insecureAcceptEverything` with an empty `/usr/share/pki/containers` and no operator-reachable way to change it; and **85-bake-plan**'s native Rust tier is *already reachable by absolute path* and currently aborts with three wrong-cause validation errors because `globals.sh` sets but never exports `MIOS_VERSION_*`. The one piece of good news is that the `command -v miosd` dispatch (task_962) is genuinely dead at bake — verified independently on eight stages — so most of the Rust-side defects are latent, which means the conversion sequencing below is the whole ballgame: repairing the dispatch globally before repairing the renderers would arm nine stages' worth of silent failures in a single bake.

## Refuted claims

Six claims were knocked down, plus one partial. The pattern matters: **every refutation was a harness artifact or a mislabelled premise, not a fabricated observation.** The mechanical readings held up in all seven cases; what failed was the causal story on top of them.

1. **76-uki-render — "with miosd on PATH the stage installs the STALE committed cmdline."** The claimant *planted* miosd on PATH, then reported the consequence as a shipped regression. `miosd` installs only to `/usr/libexec/mios` (`Containerfile:55`), which is on no `PATH` — no `ENV PATH`, no `usr/bin/miosd`, and `mios-shim-links.conf` has no miosd entry. At bake the fallback runs `${ROOT}/tools/generate-uki-cmdline.py` and regenerates from stage 75's output, so operator `[kargs]` *are* honoured. The genuine underlying issue (a dead Rust dispatch that no-ops) is already captured by two upheld findings.

2. **88-finalize — "the stage reads no SSOT at all."** The strace is correct (zero `mios.toml` opens) but `/ctx/VERSION` is not an unbound input: `Containerfile:9` is `COPY VERSION /ctx/VERSION`, and `check_version_ssot` compares `[meta].mios_version` to `$ROOT/VERSION` *and* field-by-field to the source-tree `os-release`. The claim's assertion that the gate "only compares the SOURCE-TREE usr/lib/os-release" is factually wrong. The planted-SSOT experiment edited `mios.toml` while leaving `VERSION` alone — the skew it created is exactly what the gate rejects. What survives is a naming imprecision, not a Law 7/8 violation.

3. **05-repos — "the vendored branch contradicts the SSOT (`gpgcheck` true→0, `gpgkey` dropped)."** `[repos.fedora]` declares a *metalink* repo; the SSOT has no offline stanza, so the vendored render is not a projection of that table. The four omitted keys (`timeout`, `minrate`, `max_parallel_downloads`, `ip_resolve`) are network-transfer options meaningless for a `file:///` baseurl, and `gpgcheck=0` for an image-baked mirror is the house pattern (`04-local-rpm-mirror.sh:22`). It also double-counts the real finding and is conditioned on a branch the same submission proves never runs.

4. **05-repos — "the dead `[repos]` table is pre-registered as accepted debt."** The gate works: `tables=157 consumed=154 registered-unconsumed=3 (ceiling 3)`. A shrink-only register with a documented drain procedure and a ceiling pinned at the measurement is not an Empty-Set Pass.

5. **05-repos — "the bash fallback hardcodes its output directory."** That is auditor-harness friction. `05-repos.sh` is a root-run bake stage where `/etc/yum.repos.d` is the correct destination, and every peer stage does the same. `miosd` already exposes `--output`.

6. **34-render-quadlets — "2641 of 2655 `MIOS_*` are never exported"** (and the two findings derived from it). **This is the most important refutation in the set.** The measurement came from `cd automation && bash -c 'source ./lib/common.sh'`; with that relative path, `_mios_locate_userenv` probes `./lib/../../tools/lib/userenv.sh` → `/home/user/tools/lib/userenv.sh`, outside the repo. The lookup fails silently (`|| true`), the SSOT resolver never runs, and only `globals.sh`'s non-exporting `: "${VAR:=default}"` defaults remain — hence 14. Invoked the way `build.sh:225` actually does it (absolute `$SCRIPT_DIR`), `userenv.sh` is found and evals 2607 `export MIOS_*=` lines (`shell=2720 exported=2615`). All four cited "production-shaped outputs" were fabricated by the broken harness: with real GNU envsubst the rendered values are `0.0.0.0:8110`, `tcp-listen:8120`, `http://localhost:8510/health`, `--port 8210`. The derived claim that miosd bakes a stale `chat = "qwen2.5-coder:7b"` is likewise false — it writes `granite4.1:8b`. **Trust implication: any evidence line in the original audit whose premise reads "`MIOS_*` is not exported" must be re-derived.** Note this cuts *against* the stage: it flips the env-var/vendor-name/password substitution finding from "latent trap" to live-today, and the dropped multi-LoRA post-processing from hypothetical to a real default-bake divergence.

7. **34-render-quadlets — "`MIOS_CONV_INFERENCE_HEAVY_ENGINE_MODE` is emitted by nothing, so the multi-LoRA block is dead code."** The grep of `globals.sh` is right but `globals.sh` is not the emitter that matters: `python3 usr/lib/mios/mios_toml.py --emit=shell` emits `export MIOS_CONV_INFERENCE_HEAVY_ENGINE_MODE=single`. The block fires on a default bake with no planting. (A smaller, real Law 9 smell survives: `globals.sh:605` spells the same key `MIOS_CONVERGE_...` while the resolver spells it `MIOS_CONV_...`, and the sed hardcodes `4`/`8`/`64` and `/var/lib/mios/lora-adapters`.)

8. **build.sh — "the task_962 register forgives build.sh and carries a slack slot."** Units error: `max_unreachable` counts `command -v` *sites* (15, because `98-drift-checks.sh` carries two), the array lists *files* (14). Ceiling equals measurement — zero slack — and `mios-gate/src/dispatch.rs:187-192` makes a ceiling *above* the measurement a violation in its own right. Planting one new gate produced `exit 1` with two findings.

9. **Partial — 33-generate-quadlets, "hardcoded deprecation comment and hardcoded placeholder set behind a bare except."** Part (a) upheld: the `if name == "mios-llm-heavy-alt"` branch emits a literal unit name and prose policy string into the rendered output. Part (b) refuted: the `try` path already returns `set(phs) | {"FEDORA_VERSION","MIOS_VERSION"}`, a missing `[generator]` table still takes the `try` path and returns the identical set, and the only way to reach the `except` is an unparseable TOML — which then dies loudly at `load_sidecars` with exit 1. No silent substitution is possible.

**Evidence-hygiene corrections that did not overturn a finding** (calibrate accordingly): 44-firewall's `comm -23` block pasted one line (`port=8700/tcp`) from the *planted* run into the vendor-SSOT evidence; the aiplane-lint bash citations are uniformly ~8 lines low (content verbatim correct at the real offsets); 88's newline-injection payload as quoted lands the newline *inside* the quotes and needs a quote-closing variant to actually set the key; 01's "26 bound lines" only arises when the SSOT is *also* unreadable (20 with a valid SSOT); 76's `match-architectures` count is 15/17, not 14/17; 34's residual counts are 18/27/3, not 27/27. In every case I checked, the defect stood and only a number or a pasted line was wrong.

## Conversion order

**Sequencing rule that governs everything below.** `command -v miosd` is dead at bake (task_962), and `mios.toml [build.tool_dispatch].unreachable` registers 14 files at a ceiling of 15 with zero slack. The one-line fix task_962 itself proposes — `ENV PATH=/usr/libexec/mios:$PATH` — would arm the latent Rust defects in **75, 33, 34, 40, 51, 49, 88, 01 and 05 in a single bake**. Do not do that. Convert per stage, and flip *that stage's* dispatch to an absolute path in the same commit that lands its parity gate, exactly as 35/42/43 already do. Two dispatch paths are already live and already broken and are therefore not subject to this rule: `Containerfile:103 miosd drift-check` (hollow checks) and stage 85's tier-2 `/usr/libexec/mios/mios-bake-plan` (hard-fails on unexported `MIOS_VERSION_*`).

Before stage 1, land two standalone bugfixes that are not conversions and should not wait for one: (a) make `generate-uki-cmdline.py` fail on a parse error instead of `except … continue`; (b) export `MIOS_VERSION_CEPH/_K3S/_FORGEJO` from `globals.sh` (or resolve them from SSOT in `bake_plan.rs`), which unbreaks stage 85 today.

1. **`automation/build.sh` (phase driver)** — gatekeeper. While `load_from_toml` fails open to a 6-phase registry and `[build.phases]` can silently drop a stage, no other conversion's parity claim is trustworthy. Must add `55-native-build.sh` to `[build.phases]` and a regenerate-and-diff guard in the same commit, or the first Rust-driven build deletes its own compiler step. **Output diff IMPOSSIBLE** (no artifact) — proof is a byte-diff of the ordered `ALL_SCRIPTS` list produced by `build.sh` lines 185-248 with miosd absent vs present, plus a five-case error matrix asserting non-zero exit.
2. **75-kargs-render** — feeds stage 76; fully diffable; its Rust path is irreversibly destructive (`rd.driver.pre=vfio-pci` has no other source in the tree). Gate: `diff -r` of both renderers over copies of the real `kargs.d` with `miosd` off PATH, plus idempotency (render twice, second run a no-op) and a `[kargs] # comment` fixture that forces a real TOML parse.
3. **76-uki-render** — consumes 75's output; owns the boot line; holds the worst live defect. The naive diff is **vacuous** (`run_render_uki_cmdline` execs the same python), so the commit must first add a `KERNEL_CMDLINE_DST`/`--kargs-dir`/`--out` seam and write an actual Rust renderer, then prove CWD-independence (`/`, `/tmp`, repo root must produce identical bytes) and that `--check` **fails** on a corrupt drop-in.
4. **33-generate-quadlets** — feeds 34, 01 and 85; two live security defects (secrets at 0644, env-driven `User=0`). Diffable, but run from a **non-repo CWD** and assert a **file-count floor of 30**, or the current no-op passes the diff. Add assertions that no `POSTGRES_PASSWORD` literal appears and that `MIOS_ADGUARD_UID=0` is *refused*.
5. **34-render-quadlets** — consumes 33's output. **Byte-parity is the wrong acceptance test here** and chasing it ships a broken image: on `mios-pgvector-backup.service` the Rust path is correct and the shipping envsubst path is wrong. Prove correctness instead — a post-stage `grep -rn '\${MIOS_' <scan dirs>` returning zero and failing the stage, a documented no-substitute list for systemd runtime refs, and a real recursive expander asserting `base_url = "http://localhost:8700/v1"`.
6. **01-system-files-overlay (LBI block)** — consumes the Quadlet tree; Law 3 is its whole point. Diffable as a `(name → target)` set, but add a search-root override first so fixtures don't need a mount namespace. Must assert 21 entries including `mios-coderun-sandbox@.container` and exclusion of the six firstboot-tier images, and must exit non-zero on a missing/malformed SSOT.
7. **85-bake-plan** — already live and already failing; consumes `Image=` lines from 33/34. **Diff against the python generator, not against `miosd`** (miosd execs python, so that diff is python-vs-python and byte-identical for the wrong reason), with `MIOS_VERSION_*` deliberately unset. Also pipe the Rust SBOM through `drift-checks.py bake-budget` and require exit 0 — today it prints `ERROR: bound-images.tsv missing size_gb column`. Decide in this commit whether `tools/native/mios-bake-plan` or `miosd::bake_plan` owns the stage; shipping both is Law 15 double-tracking.
8. **49-cosign-policy** — highest *posture* risk, lowest coupling, but this is not a port: the one non-permissive value the renderer can express produces a spec-invalid policy and no trust roots exist to point it at. **A naive diff is meaningless** (both branches write nothing under real bake conditions). Proof: render to an explicit `--out`, validate with `skopeo standalone-verify` or `podman --signature-policy` rather than `jq -e .`, and assert the artifact lands at the absolute `/usr/lib/containers/policy.json` inside the built image. Reconcile the 50-byte hand-edited committed file against the 76-byte generator output and register the generator in the projections table.
9. **88-finalize** — single-file, fixture-diffable *once* an `OSR="${MIOS_OSRELEASE:-/usr/lib/os-release}"` seam exists. The default-input diff is degenerate (both write back the value already there), so parity must be shown on a planted version plus symlink / CRLF / no-trailing-newline / stock-Fedora fixtures, and a hostile-version matrix with **exit codes recorded** — the commit must state which failure mode it adopts, because bash exits 1 on `|`, `\` and newline while Rust exits 0.
10. **44-firewall-ports** — **output diff IMPOSSIBLE** (mutates firewalld zone state). Proof is an argv-sequence diff: a tracing `firewall-offline-cmd` shim placed both on PATH (for bash) and at the absolute `/usr/bin/firewall-offline-cmd` (Rust hardcodes that path), both sides run through the identical stage entry point, `diff` required to be exact. Repeat against a planted `mios.toml` (new `[firewall].open_ports` entry + a changed `[ports]` value) — the Rust list is a hardcoded 15-tuple with no `--toml`, so it fails this test outright today.
11. **40-fapolicyd-trust + 51-hardening — convert as one commit.** Both dispatch to the identical argument-less `miosd harden`, which performs the union of their contracts; converting either alone makes the other's fallback dead code. **Output diff IMPOSSIBLE** — proof is a filesystem-state diff inside `unshare -m` (symlink set with targets, `stat -c '%a %U:%G'` on the wants dir and both `fapolicyd.conf` files), with the baseline being *40-bash then 51-bash in one namespace*. Split `harden` into two scoped subcommands with `--root`, and drive the roster from `[security].enable_units` — that array currently has zero consumers tree-wide, which is the stated goal of the task.
12. **05-repos** — cheap, low blast radius (only the online metalink heredoc has ever run), but the diff is **vacuous today**: all three branches are byte-identical because all three restate the same literals. The test must assert **divergence** from today's output after adding `--toml`, must repoint the offline probe at `.../vendored/rpm-mirror`, and must drop `max_unconsumed` 3→2 with `"repos"` leaving the register in the same commit.
13. **98-drift-checks `check_agent_pipe_budgets` / mios-aiplane-lint** — last, because it is a gate rather than a renderer, but it must not be skipped: it is the template for 55 hollow `Check` impls that run at every bake. **Output diff IMPOSSIBLE** — proof is an exit-code/verdict matrix. Six fixtures where the current pair agrees on a *correct* answer must stay green; four where it agrees on a *wrong* answer (agent-pipe tree deleted, keys present only in a comment, new `[agent_pipe]` keys with no consumers, a key relocated to a subtable) must **invert** to non-zero. Add `/usr/libexec/mios/mios-aiplane-lint` to the dispatch candidates, lift the nine key names into SSOT, and prove `miosd drift-check --root <nonexistent>` no longer reports `check_agent_pipe_budgets` as PASS.

## Coverage gaps

Nothing below was observed. Every one of these is a place where a conversion commit could pass its gate and still be wrong.

- **Cross-cutting:** no auditor ran a real `podman build`. Bake-time CWD (`/`) is derived from `Containerfile` (`WORKDIR` appears only at line 20 inside `rust-builder`) plus `build.sh` never `cd`-ing, not measured. No auditor ran a full `just drift-gate`. No SELinux-enforcing host was available, so `fs::write`-vs-`sed -i` context preservation and `symlink`-vs-`ln -sf` labelling are untested everywhere.
- **75-kargs-render:** no boot was performed — the consequence of losing `rd.driver.pre=vfio-pci` is inferred from the karg's meaning plus its confirmed presence in `usr/lib/kernel/cmdline`. `src/mios-rs/` test modules were not audited exhaustively for `render_kargs` coverage. The three-layer overlay was not exercised (both sides read one `--toml`).
- **76-uki-render:** `ukify` itself was never run, so downstream consumption by `77-composefs-verity.sh` / `79-boot-config.sh` is unverified — in particular whether an empty (1-byte) cmdline aborts UKI assembly later. The `rpm -q systemd-ukify` / `install_packages_strict "uki"` branch was stubbed out (no RPM DB). No `miosd drift-check` coverage for this projection was found, but `run_drift_check` was not audited end to end.
- **88-finalize:** the stage was never run end to end (it runs `systemctl preset-all`, `dnf clean all`, `rm -f /etc/containers/auth.json` before the dispatch); the bash side is a verbatim extraction of lines 44-51. No bake with a populated vendored mirror, so it is unconfirmed that `dnf` would consume the vendored stanza correctly. `06-enable-external-repos.sh` (crowdsec/ublue/terra, same `FEDORA_VERSION` and `MIOS_ONLINE_BUILD`) was not audited.

## Producer consolidation follow-up

The historical Python producer names in this audit have been replaced by the
shared Rust library at `tools/native/mios-unit-gen/src/lib.rs`. The current
UKI command is `mios-unit-gen uki-cmdline --root DIR`; `--check` compares its
projection without writing. `miosd render-uki-cmdline` calls the same library.
The ordered kargs payload was compared with the former producer before removal.
Malformed drop-ins fail before the existing cmdline is overwritten.

The Cockpit and FreeIPA producers now use `mios-unit-gen cockpit` and
`mios-unit-gen ipa-enroll`. Their former service configuration bodies are
preserved, with only the attribution comments changed. The daemon's two
projection checks call the same library. Build phases use the shared
`mios_project_config` helper and require an advertised native mode; they no
longer skip these settings when a Python producer is unavailable. FreeIPA's
Bash-sourced values retain literal shell characters through explicit escaping.
